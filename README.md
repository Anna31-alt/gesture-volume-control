# Gesture Based Volume Control System

## Overview
This project implements a computer vision based system that allows users to control system volume using hand gestures detected through a webcam.

## Technologies
Python
OpenCV
MediaPipe
Streamlit
NumPy
Matplotlib

## Project Milestones

Milestone 1
Webcam capture and hand detection using MediaPipe.

Milestone 2
Gesture recognition using distance between thumb and index finger.

Milestone 3
Distance mapped to system volume level.

Milestone 4
User interface feedback including:
Detection status
Detection accuracy
Volume history graph.

## Running the Project

Install dependencies

pip install -r requirements.txt

Run the application

streamlit run main.py
